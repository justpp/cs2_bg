# CS2 语音放歌助手

把 QQ 音乐（或本地音乐文件）混进 CS2 的语音对话，队友能直接听到。
支持全局快捷键，托盘常驻，不修改游戏文件、不注入游戏进程。

---

## 它解决什么问题

CS2 的语音只从一张"麦克风"设备取声音。想放歌，就得让那张"麦克风"里既有你说话、又有音乐。

本程序的做法是：

```
QQ 音乐 ──(进程级回环捕获)──┐
                            ├── 混音 ──> 虚拟声卡(播放端) ──> CS2 当作麦克风读取 ──> 队友
你的麦克风 ──(设备采集)────┘
```

关键在于 **进程级回环**（Process Loopback）：程序只抓 QQ 音乐这一个进程发出的声音，
不会把游戏音效、系统提示音一起抓进去。这点和普通的"系统声音录制"有本质区别。

## 快速开始

### 第 1 步：装一张虚拟声卡

推荐 **VB-Audio Virtual Cable**（免费，<https://vb-audio.com/Cable/>）。
装完重启，系统里会多出：

- 播放设备：`CABLE Input (VB-Audio Virtual Cable)`
- 录音设备：`CABLE Output (VB-Audio Virtual Cable)`

> 已有 Voicemeeter 的话，用它的虚拟输入也行。

### 第 2 步：配置本程序

双击 `Cs2VoiceMusic.exe`，右下角托盘会出现图标，双击它打开设置窗口。

**「设备」页**：

- **输出到（虚拟声卡）** → 选 `CABLE Input`
- **麦克风来源** → 选你的真实麦克风（例如 `麦克风 (Realtek High Definition Audio)`）

**「音乐槽位」页**：
给想放的歌绑定槽位。点「选择音乐…」选文件，之后游戏里按 `Ctrl+Alt+1` 就能放。

保存设置。

### 第 3 步：配置 CS2

CS2 → 设置 → 音频：

- **语音输入设备** → 选 `CABLE Output (VB-Audio Virtual Cable)`
- 其他语音相关设置保持默认即可

完成。现在按 `Ctrl+Alt+M` 开关音乐注入，队友就能听到了。

## 快捷键

只有 5 个，够用且不容易记混。程序启动后自动生效，**不需要窗口在前台**，游戏里也能用。

| 快捷键 | 作用 |
|---|---|
| `Ctrl + Alt + M` | 开 / 关音乐注入 |
| `Ctrl + Alt + 1` | 播放槽位 1 |
| `Ctrl + Alt + 2` | 播放槽位 2 |
| `Ctrl + Alt + 3` | 播放槽位 3 |
| `Ctrl + Alt + 4` | 播放槽位 4 |

同一槽位的键再按一次 = 暂停 / 继续。

想改键位：「快捷键」页点右侧按钮，直接按下新组合键即可，改完自动保存。

组合键至少要带一个修饰键（Ctrl / Alt / Shift / Win），或者用 `F1`~`F24`。
裸字母、裸数字会被拒绝——全局热键会把整个系统的这个键吞掉，游戏里也一样。

> 打开设置窗口：双击托盘图标，或者再双击一次 `Cs2VoiceMusic.exe`（不会重复启动，只会把已有窗口叫出来）。

## 音乐槽位：按一下键，放指定的歌

「音乐槽位」页有 4 个槽位，每个槽位绑定若干本地音频文件。

1. 点槽位右侧「选择音乐…」，选中一首或几首（支持多选）
2. 游戏中按 `Ctrl+Alt+1`，立刻开始放这个槽位的歌
3. 再按一次暂停，换一个槽位键就切歌

槽位可以改名（编辑 `config.json` 里的 `Name` 字段），比如「开场曲」「嘲讽曲」「胜利BGM」。

一个槽位绑了多首时，按顺序播放；放完最后一首会从头循环。
想让某个槽位放完就停，把 `config.json` 里该槽位的 `"Loop"` 改成 `false`。

**为什么用本地文件而不是直接控制 QQ 音乐**：系统媒体接口（SMTC）只能做播放/暂停/上下一首，
没法"播放某一首指定的歌"。要做到按一个键就放特定曲目，只有自己解码播放才可靠。

## QQ 音乐怎么办

QQ 音乐仍然可以正常用，有两种方式：

- **让程序捕获 QQ 音乐**：程序会自动找到 QQ 音乐的发声进程并捕获它的声音。你在 QQ 音乐里
  点哪首，队友就听到哪首。适合"随便放点什么"。
- **用槽位精确控制**：把想放的歌下载下来，绑到槽位上。适合"就要放这首"。

两者不会同时生效——一旦用槽位播放，程序会自动让位给槽位音源，避免两路声音叠在一起。
想切回 QQ 音乐，用托盘菜单「播放槽位 → 停止槽位播放」。

## 两个开关的区别

这是最容易搞混的地方：

- **音乐注入**：控制音乐进不进语音。关掉后队友只听到你说话，你本机听歌不受影响。
- **麦克风直通**：控制你说话进不进语音。关掉后队友只听到音乐。

两个都开着 = 队友同时听到你说话和音乐（正常用法）。

## 自检

想确认音频链路是否正常，打开命令行执行：

```bat
Cs2VoiceMusic.exe --selftest --run 5 --output "CABLE" --loopback "CABLE"
```

也可以用 `--slot 1` 直接验证某个槽位能不能正常出声：

```bat
Cs2VoiceMusic.exe --selftest --run 5 --slot 1 --output "CABLE" --loopback "CABLE"
```

它会：

1. 列出所有音频设备
2. 列出正在出声的进程
3. 查找 QQ 音乐进程
4. 实际跑 5 秒混音，报告音乐/麦克风电平

结果同时写到 `%APPDATA%\Cs2VoiceMusic\selftest.txt`。

看这三个数就知道通没通：

- **音乐峰值** > 0：抓到了音乐
- **麦克风峰值** > 0：抓到了麦克风
- **虚拟声卡回读峰值** > 0：声音真的写进虚拟声卡了（这一项最能说明问题）

## 常见问题

**队友听不到音乐**

1. 确认「音乐注入」是开的（概览页的开关、或按 `Ctrl+Alt+M`）
2. 看「概览 → 实时电平」，音乐条要在动
3. 如果音乐条不动，说明没抓到 QQ 音乐——确认 QQ 音乐在播放，且「设备」页的进程名匹配

**队友听到的是游戏音效**

输出设备选错了。要选虚拟声卡（`CABLE Input`），不是扬声器。

**自己听不到音乐**

虚拟声卡只把声音送进"录音端"，不会送到耳机。三个办法任选：

- QQ 音乐里保持正常输出（QQ 音乐本身还在扬声器上放，程序是旁路捕获，不影响你自己听）
- 用 VB-Cable 自带的监听功能
- 用 Voicemeeter 做分流

**音乐断断续续 / 有杂音**

把虚拟声卡的采样率统一成 48000 Hz：
Windows 设置 → 系统 → 声音 → 更多声音设置 → 选中 CABLE Input → 属性 → 高级 → 选 `2 声道，16 位，48000 Hz`。
CABLE Output 也做一遍。

**快捷键没反应**

可能被别的软件占了。到「快捷键」页看有没有红色提示，换一个组合键即可。

**按了槽位键但没声音**

1. 看「概览 → 实时电平」音乐条有没有动
2. 确认「音乐注入」是开的
3. 槽位是不是还没绑定音乐（槽位卡片上会写"还没有添加音乐"）

**QQ 音乐重启后音乐没了**

程序每 2 秒自动检测一次，会自动重新挂接，不用管。

## 使用提醒

在竞技对局里向队友放歌会影响沟通。请只在休闲、朋友局，或征得队友同意时使用。

本程序：

- 不修改任何游戏文件
- 不注入游戏进程
- 不读写游戏内存
- 只用系统标准的音频接口（WASAPI）和媒体接口（SMTC）
- 以普通用户权限运行，不需要管理员

## 技术细节

给想改代码的人：

- **进程回环**：`ActivateAudioInterfaceAsync` + `AUDIOCLIENT_ACTIVATION_TYPE_PROCESS_LOOPBACK`，
  设备路径是字符串 `VAD\Process_Loopback`。注意这个接口的 `IAudioClient` **不实现 `GetMixFormat`**
  （返回 `E_NOTIMPL`），必须自己指定格式。
- **COM 调用**：全部走 vtable 函数指针（`Audio/WasapiInterop.cs`）。原因是进程回环返回的
  `IAudioClient` 是聚合对象，托管 RCW 转换会退化成 `__ComObject`。
- **时钟**：麦克风、QQ 音乐、虚拟声卡跑在三个独立硬件时钟上，长时间必然漂移。
  混音器以渲染线程为唯一时基，缓冲积压就丢帧、不足就补静音，把延迟钉在 40~60ms。
- **共享模式**：渲染端必须用设备自己的混音格式 Initialize，否则返回
  `AUDCLNT_E_UNSUPPORTED_FORMAT (0x88890008)`。非 48k/16bit/立体声时走 `AUTOCONVERTPCM`。
- **界面图标**：播放/暂停/音符等全部用矢量 `Path` 绘制，不依赖任何字体。
  早期版本用 `Segoe MDL2 Assets` 的私有区码点，在部分精简字体环境下会渲染成
  方块或问号——改用几何图形可以从根上避免这类问题。

源码结构：

```
src/Cs2VoiceMusic/
├── Audio/
│   ├── WasapiInterop.cs       COM 定义与 vtable 调用
│   ├── AudioDeviceService.cs  设备枚举、进程回环激活
│   ├── AudioSessionProbe.cs   找出正在出声的进程
│   ├── AudioCaptureSource.cs  WASAPI 采集（麦克风 / 回环）
│   ├── AudioRenderSink.cs     WASAPI 渲染
│   ├── AudioRingBuffer.cs     无锁环形缓冲
│   ├── AudioMixerEngine.cs    混音、漂移补偿
│   └── LocalMusicSource.cs    本地文件解码播放
├── Media/SystemMediaController.cs  QQ 音乐 SMTC 控制
├── Hotkeys/HotkeyManager.cs       全局热键
├── Config/AppConfig.cs            配置
├── Ui/                            界面
└── SelfTest.cs                    命令行自检
```
